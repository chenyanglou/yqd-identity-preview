# 原起点界面预览

这是可部署到 GitHub Pages 的纯静态预览。包含登录、注册申请、等待审核、工作台、人员审核、账号授权、职位模板及示例审计界面。

**所有人员、申请和权限记录均为虚构示例。不会连接真实飞书，不会保存申请，不包含后端、数据库、密钥或真实业务数据。界面演示不能替代生产认证及权限验收。**

使用页面顶部导航切换界面，审核、拒绝、账号状态及授权等演示仅影响当前页面内存，刷新后重置。工作入口仍按当前版本状态显示“暂未开放”，没有将尚未接入的业务模块伪装成可用功能。

资源使用相对地址，页面路由使用 hash，支持 GitHub Pages 项目子路径与刷新。

仓库中的 `index.html`、`styles.css`、`preview.css`、`portal-preview.js`、`company-logo.png` 为运行资源。`preview-adapter.js` 是无网络模拟适配器源码；`.nojekyll` 关闭 Jekyll 处理；本文件为说明。八个文件均平铺在仓库根目录。

完整私有工程中运行 `node app/scripts/build-public-preview.mjs` 可从正式门户界面重新生成预览。此目录不包含生产部署能力。
